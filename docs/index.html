Open-source Agent Skill

Better ideas need honest opposition.

Idea Council helps an AI agent explore, refine, compare, challenge, and decide on early ideas. It keeps evidence separate from opinion, preserves material objections, and never turns agent agreement into proof.

Install the SkillRead the source

Use the lightest process that changes the decision.

Explore without forcing closure

Open up interpretations and possibilities when the idea is still taking shape.

Challenge the live proposal

The red team attacks the latest candidate, not a version you already abandoned.

Preserve dissent

Material objections keep stable IDs and cannot disappear in the final summary.

Separate opinion from evidence

Several agents agreeing is still not user, market, technical, legal, or safety evidence.

Research what matters

When facts are the bottleneck, the workflow looks for both support and falsification.

Keep humans in control

Consequential execution requires evidence sufficient for the exact scope and explicit authorization.

One-prompt install

Give the repository to your agent.

Install challenge-and-refine-ideas from https://github.com/fanfanfanfanfan626/challenge-and-refine-ideas. Read AI_INSTALL.md first, preserve the complete skill directory, and verify the installation before reporting success.

The package is plain Markdown and works serially on compatible Agent Skills hosts. True independent councils require isolated child contexts; otherwise the result is honestly labeled L0.
