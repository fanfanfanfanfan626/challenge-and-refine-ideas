# Support

Before opening an Issue, read the [README](README.md), [AI installation contract](AI_INSTALL.md), and [copy-paste examples](EXAMPLES.md).

- Use a **bug report** when the packaged Skill, a reference, or release validation behaves differently from the documented contract.
- Use a **feature request** for a concrete discussion or decision failure the Skill does not handle.
- Use a regular Issue for a documentation correction or a reproducible compatibility question.

Include the release or commit, host and host version, whether clean subagent contexts were available, the exact request with private details removed, and the expected versus actual behavior. Never publish credentials, confidential ideas, personal data, or private council transcripts.

Security-sensitive reports belong in the private channel described in [SECURITY.md](SECURITY.md).
